# Changelog

## 0.1.0 — Initial foundation

- Added private local-first author workspace shell.
- Added IndexedDB persistence for entries, relationships, media, and settings.
- Added typed lore/story/planning schemas, including a trilogy overview and dedicated idea-inbox statuses.
- Added canon and unresolved-question status systems.
- Added knowledge-layer fields that separate author truth from in-world belief and reader knowledge.
- Added structured cross-linking.
- Added dashboard, world, character, geography, maps, history, story, mysteries, timeline, media, idea, question, and settings views.
- Added global and section search/filtering, including media search.
- Added media reuse and local image storage.
- Added full JSON backup/restore including media.
- Added responsive dialogs constrained to the viewport.
- Added static offline shell caching and no-index metadata.
