# Roadmap

## V0.1 — Foundation

Implemented:

- local IndexedDB database
- typed entries
- canon status model
- knowledge layers
- cross-linking
- search/filtering
- characters, geography, history, story, mysteries, ideas, questions
- timeline
- media reuse
- image-based Maps section
- JSON backup/restore
- responsive desktop/mobile shell

## V0.2 — Authoring Workflow

Recommended next release:

- Convert Idea into Entry without copy/paste
- Parent-location picker backed by structured relationships
- Chapter parent Book and Scene parent Chapter helpers
- Mystery clue subrecords linked to chapters/scenes
- Dedicated Trilogy Overview record/view
- Reader-knowledge reveal records with Book/Chapter/Scene links
- Recent-created vs recent-edited distinction on Dashboard
- Safe soft-archive flow before permanent deletion

## V0.3 — Timeline & Maps

- explicit historical date model: display text + sortable range + uncertainty type
- era bands and filters
- map records with image version/history
- marker placement against stable location IDs
- historical/political/physical map variants

## Later

- relationship graph
- reveal/foreshadowing visualization
- ZIP backups
- Markdown export
